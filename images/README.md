# Фотографии товаров

Положи сюда файлы `.jpg` — сайт подхватит их сам, править код не нужно.
Если файла нет, на его месте остаётся штриховой чертёж, и ничего не ломается.

## Имена файлов

| Файл | Куда попадёт |
|------|--------------|
| `hero.jpg`    | большая картинка на обложке (вместо чертежа дивана) |
| `barokko.jpg` | диван «Барокко» |
| `nord.jpg`    | угловой диван «Норд» |
| `chester.jpg` | диван «Честер» |
| `mila.jpg`    | кушетка «Мила» |
| `tuluza.jpg`  | кресло «Тулуза» |
| `oval.jpg`    | кресло «Овал» |
| `lotta.jpg`   | банкетка «Лотта» |
| `kube.jpg`    | пуф «Кубе» |

Имя должно совпадать точно, строчными латинскими буквами, расширение `.jpg`.

## Каким должно быть фото

- **Пропорции** — примерно 420 × 264 (шире, чем выше). Другие пропорции
  тоже подойдут: карточка обрежет фото по центру, но лучше не брать
  вытянутые вертикальные снимки.
- **Размер по ширине** — 800–1200 пикселей достаточно. Файлы тяжелее
  300 КБ лучше сжать, иначе сайт будет медленно грузиться.
- **Фон** — тёмный или нейтральный смотрится уместнее: сайт тёмный,
  и белые студийные фоны будут выбиваться яркими пятнами.

## Где взять фотографии

- Свои снимки — единственный вариант, если мебель настоящая.
- Бесплатные фотобанки без обязательной подписи автора:
  [Unsplash](https://unsplash.com/s/photos/sofa),
  [Pexels](https://www.pexels.com/search/sofa/).
  Скачать, переименовать по таблице выше, положить в эту папку.

Учти: модели в каталоге вымышленные, поэтому стоковое фото не будет
точно соответствовать заявленным размерам и обивке.
