# Telegram Mini App «Конвертер»

Приложение внутри Телеграма: курсы валют в реальном времени и единицы измерения
(длина, вес, объём, температура, площадь, скорость). Бот нужен только чтобы
открыть приложение — вся работа происходит в веб-интерфейсе.

Бот: [@cshconverter_bot](https://t.me/cshconverter_bot)
Приложение: https://tochkaq1-afk.github.io/converter/

## Как устроено

```
telegram-bot/           бот: одна кнопка, открывающая приложение
├── bot.py              точка входа, polling + кнопка меню
├── config.py           токен и адрес приложения
└── handlers/start.py   /start, /help

converter/              само приложение (лежит в корне репозитория,
├── index.html          чтобы попасть на GitHub Pages)
├── styles.css          тёмный премиум, всё через CSS-переменные
├── data.js             валюты и коэффициенты единиц
├── app.js              логика, анимации, кэш курсов
├── tweak.css
└── tweak.js            панель живой подстройки вида
```

Курсы — [open.er-api.com](https://open.er-api.com): бесплатно, без ключа,
запрос идёт прямо из браузера, ответ кэшируется в `localStorage` на час.
Единицы считаются на устройстве и работают без сети.

## Запуск бота

**1. Токен.** [@BotFather](https://t.me/BotFather) → `/newbot` → скопировать токен.

**2. Файл `.env`** рядом с `bot.py` (скопируй `.env.example`):

```
BOT_TOKEN=7123456789:AAH...
```

**3. Установка и запуск:**

```bash
pip install -r requirements.txt
python bot.py
```

Бот работает, пока запущен процесс. Останов — `Ctrl+C`.

Приложению сервер не нужен: это статические файлы на GitHub Pages.
Telegram открывает Mini App только по публичному HTTPS — `localhost` не подойдёт.

## Твикер

Панель живой подстройки: шестерёнка в углу, клавиша `~` или адрес с `?tweak=1`.
Меняет палитру, шрифты, форму, скорость и характер анимаций, заставку.
Настройки хранятся в `localStorage`, кнопка «JSON» копирует отличия от исходных —
их можно вписать в `DEFAULTS` в `app.js`, чтобы стали значениями по умолчанию.
