# ЛЕКАЛО — производство мягкой мебели

Демонстрационный сайт мебельного производства: каталог диванов, кресел и пуфов
с работающей корзиной. Мой первый проект на HTML, CSS и JavaScript.

## О дизайне

Тёмная палитра (графит + латунь) и высококонтрастная типографика Bodoni Moda.
Вместо фотографий товары нарисованы штриховой графикой — как лекала
(выкройки) в мастерской. Отсюда и название.

## Что уже работает

- Каталог из 8 моделей с фильтром по категориям
- Корзина: добавление, изменение количества, удаление, подсчёт суммы
- Сохранение корзины в `localStorage` — товары остаются после закрытия браузера
- Выдвижная панель корзины: закрывается по `Esc`, клику по фону и не отпускает фокус
- Форма заявки с проверкой имени и телефона
- Адаптивная вёрстка от 375 px до широких экранов
- Учёт настройки «уменьшить движение» (`prefers-reduced-motion`)

## Структура

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка и весь текст сайта |
| `styles.css` | Оформление: переменные цветов, сетки, адаптив |
| `script.js` | Каталог, фильтры, корзина, форма, анимация появления |
| `images/` | Фотографии товаров — подхватываются сами, см. `images/README.md` |

## Как открыть

Скачать файлы и открыть `index.html` в браузере — сборка не нужна,
зависимостей нет. Шрифты подгружаются с Google Fonts, поэтому для
точного вида нужен интернет; без него подставится системный шрифт.

## Важно

Это учебный проект. Бэкенда нет: заявка из формы никуда не отправляется,
а остаётся в браузере. Цены, отзывы, адрес и телефон вымышленные.
